# 🚀 PavoTweak Windows Performance Suite — Booster Edition

PavoTweak Booster Edition is an exclusive, server-side verified Windows gaming and system optimization tool available to members who contribute **at least 2 Server Boosts** to the Pavo Discord server.

---

## 💎 How to Access

1. **Boost the Discord Server:** Contribute at least 2 Server Boosts.
2. **Get Verified:** Ask staff/admin to run `/pavo-verify @your_user` in Discord. You will receive the `Pavo Booster` role.
3. **Generate Code:** In any server channel, type:
   ```text
   /pavo-access
   ```
4. **Launch PavoTweak CLI:**
   - Double-click `Launch-PavoTweak.bat` (or open PowerShell as Administrator and run `.\PavoTweak.ps1`).
   - Enter your single-use code (`PVBOOST-XXXXX-XXXXX`).

## 🔒 Security & Auto-Revocation

- **Server-Side Authorization:** The client does not store master keys or database credentials.
- **Single-Use Codes:** Temporary codes expire after 5 minutes and are burned immediately after exchange.
- **Real-Time Revocation:** If you stop boosting the Discord server or remove your boosts, your CLI session is immediately revoked (`403 ACCESS_REVOKED`).
